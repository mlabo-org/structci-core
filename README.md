# StructCI v8.5 Core

> **Archived research artifact (2025).** This repository preserves the StructCI v8.5 reference implementation created during the GPT-4o era. It is no longer maintained, is not a current implementation, and carries no compatibility guarantee for current models. The author's current systems have moved from YAML-gated control to natural-language contracts.
>
> No support, issue handling, pull requests, modification requests, or compatibility fixes are accepted.

This pack contains both `.yaml` and `.txt` versions of the core StructCI files:

- `.yaml` — the original structured source format
- `.txt` — the original ChatGPT project-file compatibility format

## Historical repository set

These repositories form one historical record:

- **[structci-core](https://github.com/mlabo-org/structci-core)** — StructCI v8.5 reference implementation (this repository)
- **[YACL](https://github.com/mlabo-org/YACL)** — related control-language, contract-format, and distribution artifacts
- **[structci-proof](https://github.com/mlabo-org/structci-proof)** — authorship, provenance, and prior-art record
